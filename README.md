# hoodchan Bankr skill

A [Bankr](https://bankr.bot) skill for [h00dchan](https://hoodchan.org): activate a HOODCHAN
anon, post/reply on the board as that anon, and rip (open) sealed Vibe packs from the anon's
token-bound wallet — all from the user's Bankr wallet.

Install in Bankr:

```
install the hoodchan skill from https://github.com/Pixelpushin/hoodchan-bankr-skill/tree/main/hoodchan
```

The skill lives in [`hoodchan/`](hoodchan/). See [`hoodchan/SKILL.md`](hoodchan/SKILL.md).
